# 跨国临床试验随机分组、发药对账与召回控制台

源提示词摘要：研究中心按分层因素生成随机分组；药品管理员只见发药信息，研究角色正常情况下不可见治疗组；重复受试者和编号冲突被阻止；紧急揭盲需填写原因并形成不可删除审计记录，断网提交进入待处理队列。药房按随机号发药、药盒按批号管理；三源并入台账对账，同一随机号只留一份有效发药单；按批号与近效期先出（FEFO）挑盒，库存不足退回说明；批号一次召回、逐人换药，分组与揭盲记录不动；断网申请先留本中心，恢复后按次序补录。

## 技术栈

## 可用流程

- 入组：机构、分层因素和受试者编号校验后生成分层区组随机号与治疗组。
- 防重复：相同身份标识或研究中心编号会拒绝再次入组。
- 角色隔离：研究者、药品管理员和监察员看到不同的分组隐藏规则；治疗组对药品管理员始终隐藏，揭盲原因仅研究者可见；发药编号与药盒批号仅药品管理员可操作。
- 安全审计：紧急揭盲要求原因，添加后只能追加，不能删除或改写。
- 离线队列：模拟离线提交进入待提交队列，联网后由授权人员确认入库。
- 发药对账：随机号 × 发药单 × 药盒批号三源并入台账，一随机号仅一份有效单；重复发药、无盒可发均退回并说明，不产生单据。
- FEFO 选盒：跳过已过期与已召回批号，按有效期升序（近效期先出）挑盒。
- 批号召回：一次查出全部在用该批号的受试者并逐人换药，旧单标记 exchanged 留痕；无合格药盒的受试者原单挂起 awaiting-exchange（退回待补药）；随机分组（arm）与揭盲记录全程不修改。
- 断网发药：申请只留本中心队列（不分配发药编号、不占盒），恢复后严格按队列次序逐条补录，库存不足的条目退回并继续后续条目。

- 7 名已随机受试者，其中 4 人持召回候选批号 B2026-03 的有效发药单。
- 合格替代盒 4 个：近效期 B2026-11×2、长效期 B2027-01×2；B2025-11、B2026-09 已过期。
- 召回 B2026-03 可一次查出 4 人：3 人换发成功、1 人因库存不足退回挂起待补。
